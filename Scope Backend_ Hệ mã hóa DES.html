1Mục tiêu Backend

Cài đặt DES theo đúng chuẩn trong bài giảng (khối 64 bit, khóa 64 bit, 16 vòng), mở rộng cho văn bản dài bằng chế độ ECB và padding PKCS#7, cung cấp API mã hóa, giải mã, xử lý file và trace từng bước. BE là nguồn đúng cho mọi kết quả mật mã; FE chỉ kiểm tra định dạng đầu vào.

Không được dùng thư viện mật mã có sẵn cho lõi DES, vì mục tiêu môn học là cài đặt thuật toán. Thư viện chuẩn chỉ dùng trong test để đối chiếu kết quả.

2Thông số và quy ước

3Đặc tả thuật toán

Pseudocode độc lập ngôn ngữ. Bit được biểu diễn bằng mảng 0/1 đánh số từ 1 như trong bảng; khi cài đặt có thể dùng số nguyên 64 bit và phép dịch, miễn là cho kết quả giống hệt bộ test.

// 3.1 Tiện ích
permute(bits, table)  = [ bits[table[i]] for i in 1..len(table) ]
rotateLeft(half, n)   = half[n+1..28] + half[1..n]
// 3.2 Sinh khóa con
keySchedule(key64):
  k56 = permute(key64, PC1)              // 56 bit, đã bỏ bit chẵn lẻ
  C = k56[1..28]; D = k56[29..56]
  for n in 1..16:
    C = rotateLeft(C, LS[n]); D = rotateLeft(D, LS[n])
    K[n] = permute(C + D, PC2)           // 48 bit
  return K
// 3.3 Hàm f
f(R32, K48):
  x = permute(R32, E) XOR K48            // 48 bit
  out = []
  for i in 1..8:
    B   = x[6i-5 .. 6i]
    row = 2·B[1] + B[6]                  // bit đầu + bit cuối
    col = 8·B[2] + 4·B[3] + 2·B[4] + B[5]  // 4 bit giữa
    out += to4bits(S[i][row][col])
  return permute(out, P)                 // 32 bit
// 3.4 Một khối
desBlock(block64, K, decrypt):
  keys = decrypt ? reverse(K) : K
  t = permute(block64, IP); L = t[1..32]; R = t[33..64]
  for i in 1..16:
    (L, R) = (R, L XOR f(R, keys[i]))
  return permute(R + L, IP_INV)          // chú ý: R16 đứng trước
// 3.5 Nhiều khối
encrypt(text, key, opts):
  K = keySchedule(parseKey(key))
  data = opts.inputFormat == "hex" ? parseHex(text) : pkcs7Pad(utf8(text))
  return hex( ECB/CBC(desBlock(·, K, false), data, opts.iv) )
decrypt(cipherHex, key, opts):
  K = keySchedule(parseKey(key))
  data = ECB/CBC(desBlock(·, K, true), parseHex(cipherHex), opts.iv)
  if opts.outputFormat == "hex": return hex(data)
  return utf8Decode(pkcs7Unpad(data))    // DES-E07, DES-E08
// CBC: mã hóa  C_i = E(P_i XOR C_(i-1)), C_0 = IV
//      giải mã P_i = D(C_i) XOR C_(i-1)

Độ phức tạp O(n) theo số khối. Có thể tối ưu bằng bảng tra kết hợp S-box và P (SP-box) sau khi đã pass toàn bộ test vector, nhưng không bắt buộc.

4Luồng xử lý

  1. Nhận requestJSON (/encrypt, /decrypt, /trace) hoặc multipart (/file). Kiểm tra kích thước ≤ 5 MiB (DES-E12) và giá trị tham số (DES-E10).
  2. Chuẩn hóa và kiểm tra khóaBỏ khoảng trắng, kiểm tra hex (DES-E03) và độ dài 16 (DES-E04). Đối chiếu danh sách khóa yếu và nửa yếu sau khi xóa bit chẵn lẻ (W01, W02).
  3. Chuẩn bị dữ liệuMã hóa văn bản: rỗng thì DES-E01, mã UTF-8 rồi đệm PKCS#7. Dữ liệu hex: bỏ khoảng trắng và xuống dòng, kiểm tra ký tự (DES-E05) và độ dài bội 16 (DES-E06).
  4. Sinh 16 khóa conMột lần cho mỗi request, dùng cho mọi khối.
  5. Xử lý từng khốiECB hoặc CBC; giải mã dùng khóa con theo thứ tự đảo.
  6. Hậu xử lýMã hóa: xuất hex in hoa, kiểm tra khối lặp trong ECB (W03). Giải mã sang text: gỡ padding (DES-E07), giải mã UTF-8 (DES-E08).
  7. Trả kết quả và ghi lịch sử{"success": true, "result": …, "warnings": [...]}. Ghi một bản ghi lịch sử với cipher = "des" theo cơ chế hiện có.

POST /api/des/file

  • Multipart: file (.txt, UTF-8, ≤ 5 MiB), key, action = encrypt | decrypt, mode, iv, response_mode = content | file.
  • action = encrypt: nội dung file là văn bản, luôn theo inputFormat = text. Kết quả là chuỗi hex; với response_mode = file trả file <tên>.des.txt.
  • action = decrypt: nội dung file là chuỗi hex (cho phép xuống dòng), luôn theo outputFormat = text. File trả về <tên>.decrypted.txt.
  • Giống các cipher khác: FE gọi content để xem trước, rồi gọi file để tải, tên file lấy từ Content-Disposition.

10Bản cài đặt tham chiếu

Cài đặt đặc tả trên, chạy trên trình duyệt, dùng để đối chiếu output khi viết unit test. Khi dữ liệu là đúng 1 khối hex, trang hiện thêm trace giống response của /api/des/trace.

Dữ liệu

Kết quả

Chọn “hex” cho bài tập một khối; chọn “văn bản” để thử padding và UTF-8. Khi giải mã, định dạng này là outputFormat.

11Tiêu chí nghiệm thu Backend

  • Lõi DES tự cài đặt, không gọi thư viện mật mã; thư viện chỉ xuất hiện trong test.
  • Unit test pass toàn bộ T01–T20, cả chiều mã hóa và giải mã cho các vector thành công.
  • Từng hàm con khớp giá trị trung gian của T01: K1…K16, Li/Ri 16 vòng, f vòng 1 = 234AA9BB.
  • Kiểm thử ngẫu nhiên 1000 lần: decrypt(encrypt(x)) = x với văn bản UTF-8 ngẫu nhiên, cả ECB và CBC; kết quả trùng với thư viện chuẩn.
  • Mỗi lỗi DES-E01…E13 có ít nhất một test API trả đúng HTTP status và message.
  • Response giữ đúng format chung {success, result | message}; FE hiện tại gọi được mà không cần sửa API client.
  • /api/des/trace cho T01 khớp mẫu mục 7.
  • File 5 MiB mã hóa và giải mã xong dưới 2 giây.
  • Lịch sử ghi bản ghi cipher = "des"; log ứng dụng không chứa khóa.

12Ngoài phạm vi

  • 3DES và AES, có thể làm ở tuần sau dùng lại desBlock.
  • Các chế độ CFB, OFB, CTR; sinh khóa từ mật khẩu (KDF); xác thực bản mã (MAC).
  • Demo vét cạn khóa hoặc thám mã vi sai, tuyến tính.
  • Kiểm tra và tự sửa bit chẵn lẻ của khóa.
